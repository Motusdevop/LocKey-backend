LocKey Access Tester

Тестовая страница для online и MVP offline-потока: выпустить access_code, проверить вход по коду замка и заранее сохранить offline_ticket для BLE-фолбэка.

1. Выпуск access code

Endpoint: POST /api/v1/external-crm/access-code

2. Проверка доступа и открытие

Endpoint: POST /api/v1/locks/{lock_id}/verify-access. Замок должен быть онлайн по WebSocket и показывать актуальный код.

3. MVP offline ticket

Issue: POST /api/v1/offline-tickets/issue. Verify: POST /api/v1/offline-tickets/verify. В реальном offline-сценарии backend уже не участвует, этот verify нужен как эталон и тест.
